## M1 — Cue language + Kokoro speaking [MUST]

### Cue spec (`cue/spec.ts`)

Line-based. One beat per line. Tags are `[tag args]`. Everything that isn't a tag is speech.

| Tag | Args | Meaning |
|---|---|---|
| `[pause N]` | seconds, clamp 0.2–6 | silence on the timeline |
| `[whisper]` `[slow]` `[trembling]` `[shout]` | — | style for the **rest of that line** |
| `[breath]` `[sigh]` `[gasp]` `[laugh]` | — | non-verbal at that point |
| `[sfx NAME]` | creak, knock, footsteps, door, heartbeat, static, drip, scrape, whispers | one-shot sound |
| `[light MODE]` | `flicker`, `blackout N`, `red`, `pulse`, `calm` | visual effect |
| `[ambient MODE]` | `low`, `swell`, `stop` | drone bed control |
| `[photo reveal ID]` | e.g. `room_1` | fade the user's photo in at the climax |

Rules:
- Case-insensitive tag names; tolerate extra spaces, `(pause 2)`, `*pause*`-style junk by dropping it.
- Unknown tag → dropped + `console.warn` + counted in DebugPanel ("3 unknown tags dropped").
- Lines that are only tags produce only events.

### Parser output (`cue/parser.ts`)

```ts
type CueEvent =
  | { kind: "speech"; text: string; style: Style }
  | { kind: "nonverbal"; nv: NonVerbal }
  | { kind: "pause"; seconds: number }
  | { kind: "sfx"; name: SfxName }
  | { kind: "light"; mode: LightMode; seconds?: number }
  | { kind: "ambient"; mode: AmbientMode }
  | { kind: "photo"; id: string };
```

Must support **incremental parsing** (feed chunks as the LLM streams; emit events per completed line).

### Segmenter (`cue/segmenter.ts`)

- Split speech into sentences.
- Merge consecutive same-style sentences up to `adapter.caps.maxChars` and a soft target (Kokoro: 1 sentence; ElevenLabs: ≤ 350 chars).

### Kokoro adapter (`adapters/tts/kokoroWeb.ts` + worker)

- Load `kokoro-js` in a worker; WebGPU if available else WASM; q8 weights. Model load progress → UI.
- Voice picker populated from the library's voice list. Default to a low, calm voice.
- `synth(seg)` → `AudioBuffer` (worker returns Float32Array + sampleRate).
- Use the library's speed option for `slow`.

### Tests

`cue/parser.test.ts`: every tag, malformed tags, style scope, incremental chunk boundaries splitting a tag mid-way, empty input, pause clamping.

**Accept:** a "Play sample" button reads `public/sample/sample.cue.txt` and speaks it through Kokoro with correct pauses (pauses just as silence for now).

## M2 — Engine: timeline, audio, effects [MUST]

### Prerender → schedule → play

1. **Prerender ("Summoning…")**: synthesize all speech segments first (Kokoro concurrency 1, ElevenLabs 2). Progress: "Summoning… 7/23". Prerender is the default for all providers.
2. **Schedule** (`engine/timeline.ts`): walk events with a time cursor. Speech advances by buffer duration; pause advances by N; sfx/light/ambient/photo are stamped at the cursor. Output a flat list of timed events.
3. **Play** (`engine/player.ts`): schedule all audio sources against `AudioContext.currentTime`. Visual effects run from a `requestAnimationFrame` loop reading the same clock, so lights stay synced with audio.
4. Controls: Play, Pause (`ctx.suspend`), Stop, Replay (no re-synthesis). Space toggles pause.

### Audio graph (`engine/audioGraph.ts`)

```
voice ─► styleChain ─► voiceBus ─┬─► dry ───────────► master ─► destination
                                 └─► reverb (convolver, procedural IR) ─┘
ambient ─► ambientBus (ducked by voice via gain automation) ─► master
sfx ─► sfxBus ─► master
```

- Procedural impulse response (decaying noise, ~2.5 s).
- Ducking: lower ambient ~6 dB while speech plays (schedule gain ramps from the timeline; no analyser needed).

### Ambient (`engine/ambient.ts`) — procedural

- Brown/pink noise through low-pass (~400 Hz) + two detuned low sine/triangle oscillators (~45–60 Hz) + slow LFO on filter cutoff. `low` = quiet bed, `swell` = ramp up over ~4 s, `stop` = fade out ~3 s.

### SFX (`engine/sfx.ts`) — procedural first

- heartbeat (two thumps, low sine + envelope), knock (filtered noise bursts ×3), creak (sawtooth with pitch wobble through band-pass), footsteps, drip, static, scrape, door, whispers (band-passed noise with amplitude flutter).
- If a sound is unconvincing, allow a CC0 file in `public/sfx/` with credit in `public/sfx/ATTRIBUTION.md`.

### Effects (`engine/effects.ts`) — CSS overlay layer over the Stage

- `flicker`: randomized opacity bursts on a full-screen overlay for 0.6–1.5 s.
- `blackout N`: overlay to near-black for N seconds, then recover.
- `red`: slow red tint + vignette for ~6 s.
- `pulse`: vignette breathing, synced to heartbeat if present.
- `calm`: clear all.
- **Reduce flashing** toggle: flicker → slow dim; blackout → 1.5 s fade; never more than 3 luminance changes per second.
- Photosensitivity notice on first play (stored dismissal).

### Transcript

- Show the current line on Stage, large serif, fading in line by line. Tags hidden. Whisper lines rendered smaller/italic.

**Accept:** sample script plays with drone, ducking, at least 5 SFX working, flicker/blackout/red synced, pause/resume works, reduce-flashing works.

## M3 — LLM adapter + Director (text-only) [MUST]

### LLM adapter (`adapters/llm/openaiCompat.ts`)

```ts
interface LLMAdapter {
  id: string;
  caps: { vision: boolean; streaming: boolean; local: boolean };
  chat(req: { messages: ChatMessage[]; temperature?: number; maxTokens?: number; json?: boolean },
       signal?: AbortSignal): AsyncIterable<string>;
}
```

- `POST {baseUrl}/chat/completions`, `stream: true`, SSE parsing via `lib/sse.ts`. `Authorization: Bearer <key>` only if a key is set.
- Images as content parts: `{ type: "image_url", image_url: { url: "data:image/jpeg;base64,..." } }`.
- `local` = host is `localhost`, `127.0.0.1` or `[::1]`.
- Presets (`presets.ts`): **Ollama** (`http://localhost:11434/v1`), **LM Studio** (`http://localhost:1234/v1`), **llama.cpp server** (`http://localhost:8080/v1`), **Custom** (any OpenAI-compatible URL). Model name is a free text field with a "Fetch models" button (`GET {baseUrl}/models`).
- Default model: the Gemma 4 E4B tag from the Ollama library — **confirm the exact tag with `ollama list` / the Ollama library page; don't guess**. Must be editable.
- Friendly errors: connection refused → "Is Ollama running? Did you set OLLAMA_ORIGINS?" with a copyable command.

### Scare profiles (`director/profiles.ts`)

| Lvl | Name | Words | Jump scares | Effects budget | Ending | Content ceiling |
|---|---|---|---|---|---|---|
| 1 | Campfire | 350–450 | 0 | ≤ 3, only `pulse`/`calm` | warm, resolved | eerie only |
| 2 | Uneasy | 400–550 | 1 | ≤ 5 | ambiguous | eerie, no violence |
| 3 | Haunted | 450–650 | 2 | ≤ 8, blackout allowed | ambiguous | implied threat |
| 4 | Dread | 550–750 | 3 | ≤ 12, red allowed | bleak | implied violence, no gore |
| 5 | Nightmare | 600–800 | 4 | ≤ 16, all | twist: it's in your room *now* | implied violence, no graphic gore |

Every level: no sexual content, no harm to children, no self-harm, no real people named unless the user typed the name in notes.

### Director prompt (`director/prompts.ts`)

System prompt (template; fill from profile + memories):

```
You write and direct short horror audio dramas that are performed aloud to one listener in a dark room.

LISTENER'S PLACE (from their own photos):
{{inventory_json_or "No photos. Invent an ordinary modern home."}}

LISTENER'S NOTES:
{{notes_or "None."}}

SCARE LEVEL {{level}} — {{name}}:
- Length: {{words}} words of spoken text.
- Jump scares: {{jumps}}. Build slowly; earn each one with silence first.
- Effects budget: at most {{budget}} [sfx]/[light] tags in total.
- Ending: {{ending}}.
- Content limits: {{ceiling}}. Never sexual content, never harm to children, never self-harm.

WRITING RULES:
1. Second person, present tense ("You hear..."). Written for the ear: short sentences, rhythm, repetition.
2. Set it in the listener's place. Use at least 3 concrete objects from the inventory, by name, where they are.
3. Output ONLY the cue script. One beat per line. No title, no markdown, no notes, no explanations.
4. Use ONLY these tags, exactly as written:
   [pause N] [whisper] [slow] [trembling] [shout] [breath] [sigh] [gasp] [laugh]
   [sfx creak|knock|footsteps|door|heartbeat|static|drip|scrape|whispers]
   [light flicker|blackout N|red|pulse|calm] [ambient low|swell|stop]
   {{photo_rule}}
5. Silence is your strongest tool. Use [pause] generously before reveals.
6. Start with [ambient low]. End with [pause 3] then [ambient stop].
7. Never mention AI, models, photos, or that this is a story.

EXAMPLE STYLE (do not reuse its content):
[ambient low]
You told yourself the hallway light was off when you left.
[pause 1.5]
[whisper] It isn't now.
[sfx creak] [light flicker]
[pause 3]
The grey coat on your door [pause 0.8] [slow] has one sleeve raised.
[gasp] [light blackout 3]
```

`photo_rule` when photos exist: `Use [photo reveal {{best_id}}] exactly once, at the climax.` Otherwise: `Do not use [photo reveal].`

User message: `Begin.` Temperature 0.9.

### Director (`director/director.ts`)

- Stream tokens → incremental parser → events. Show streamed text live (dimmed) during "Summoning".
- **Repair:** if the finished output has < 10 speech words or 0 tags, retry once with an added line: "Your previous output broke the format. Output only the cue script." If it still fails, play what we have.
- Record time-to-first-token, total generation ms, approximate tokens/s.

**Accept:** with Ollama + Gemma running locally, pressing **Tell me a story** at each level produces a playable story; level differences are audible/visible.

## M4 — Memories + vision pass [MUST]

- MemoriesPanel: add up to **4** photos (file input + drag-drop) and a free-text notes field. Thumbnails, delete, IDs `room_1..room_4`.
- `memories/imagePrep.ts`: downscale (longest side 768px), JPEG 0.8, strip EXIF by re-encoding through canvas.
- Store originals' downscaled copies + inventories in IndexedDB. Nothing persists outside the browser.
- `memories/vision.ts`: one call per photo, temperature 0.2, request JSON (`json: true`; if the endpoint ignores it, extract the first `{...}` block). Validate shape; on failure retry once, then fall back to the raw text as a free-form description.
- Cache inventory per photo hash — never re-analyze the same photo.
- Choose `best_id` for the reveal = photo with the most `unsettling_potential` items.
- If the model has no vision (`caps.vision === false` or the call errors with image content), tell the user plainly and use notes only.

### Vision prompt

```
You are a set designer for a horror radio play. You will see one photo of a real place from the listener's life.
Describe only what is physically visible, concretely, as material for a story set in this exact place.
Never identify anyone or describe a person's face, age, body or identity. If a person is visible, write only "a person" and where they are.
Return ONLY JSON:
{
  "place": string,
  "time_of_day": string,
  "lighting": string,
  "objects": [{ "name": string, "where": string, "detail": string }],
  "textures_and_sounds": string[],
  "unsettling_potential": string[]
}
"objects": 5–12 items. "unsettling_potential": 3–5 small real details that could turn eerie (a door ajar, a coat on a hook, a dark window).
```

### Photo reveal (`engine/photoReveal.ts`)

- Canvas over the Stage: desaturate, slight red tint, film grain (regenerated per frame), subtle scale drift 1.0→1.04, faint vertical displacement glitch for ~150 ms twice. Fade in 1.5 s, hold ~4 s, fade out 2 s. Respect reduce-flashing (no glitch).

**Accept:** with 2 photos of a real room, the story names objects that are actually in the photos, and the reveal fires at the climax.

## M5 — ElevenLabs adapter, router, cache, privacy badge [MUST]

### TTS interfaces (`adapters/tts/types.ts`)

```ts
type Style = "normal" | "whisper" | "slow" | "trembling" | "shout";
type NonVerbal = "breath" | "sigh" | "gasp" | "laugh";

interface TTSAdapter {
  id: "kokoro-web" | "elevenlabs" | "voice-server";
  label: string;
  caps: {
    styles: Set<Style>;          // natively supported styles
    nonverbals: Set<NonVerbal>;  // natively supported non-verbals
    offline: boolean;
    latency: "low" | "high";
    maxChars: number;
  };
  synth(seg: { text: string; style: Style; leadingNonverbal?: NonVerbal; voice: string },
        signal?: AbortSignal): Promise<AudioBuffer>;
}
```

### ElevenLabs (`adapters/tts/elevenlabs.ts`)

- `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}?output_format=mp3_44100_128`, header `xi-api-key`, body `{ text, model_id: "eleven_v3" }`. Decode with `decodeAudioData`.
- Voice picker: `GET /v1/voices` once a key is entered.
- `maxChars` 5000 but segment target ≤ 350 for prosody.
- If the browser blocks the call (CORS), show a clear error. Don't build a proxy unless I ask.

### Router + style map (`adapters/tts/router.ts`, `styleMap.ts`)

For each segment, ask the adapter what it supports and fill gaps:

| Cue | ElevenLabs (native tag prefix) | Kokoro (emulation) |
|---|---|---|
| whisper | `[whispers]` | gain 0.6, high-pass 300 Hz, reverb send ↑, speed 0.95 |
| slow | `[slowly]` | Kokoro speed 0.8 |
| trembling | `[nervous]` | detune LFO ±15 cents @ 6 Hz on the source |
| shout | `[shouts]` | gain 1.2 + soft clip |
| breath/sigh/gasp/laugh | `[sighs]`, `[gasps]`, `[laughs]`; breath → SFX | procedural SFX sample |

Keep the whole mapping in `styleMap.ts`. **Verify the exact v3 tag spellings against the ElevenLabs v3 prompting guide** before finalizing.

### Audio cache (`lib/cache.ts`)

- Key: `sha256(provider | voice | style | nonverbal | text)`. Value: encoded audio (store mp3 bytes for ElevenLabs, Float32 PCM for Kokoro). IndexedDB.
- Replays and re-renders of identical segments never re-call the provider. Show "cache hits: N" in DebugPanel. Button: "Clear audio cache".

### DataFlowBadge

Computed from settings:
- 🟢 **Fully local** — LLM host local AND TTS offline.
- 🟡 **Story text → ElevenLabs. Photos stay on this device.** — LLM local, TTS ElevenLabs.
- 🔴 **Photos are sent to {host}** — LLM host not local AND photos present.

Clicking it opens a small table: what goes where.

**Accept:** same story can be rendered with Kokoro and ElevenLabs from the Stage via a provider toggle; second render of the same story hits the cache 100%.
